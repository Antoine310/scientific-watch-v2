## ConTExT: A Generic Approach for Mitigating Spectre

- **Date de publication :** 2020-01-01
- **Pertinence :** 85/100
- **Conférence / Revue :** Network and Distributed System Security Symposium *(source : OpenAlex)*
- **Repère de veille :** conférence prioritaire pour la lecture (liste interne, pas un classement ICORE)

Cet article présente ConTExT (Considerate Transient Execution Technique), une approche générique et minimale pour atténuer les attaques Spectre. En empêchant les données secrètes de quitter les registres de manière transitoire, ConTExT modifie l'architecture pour rendre la résolution de Spectre possible en logiciel, tout en proposant une variante logicielle pure (ConTExT-light) pour les processeurs existants. L'évaluation montre une protection complète contre les variantes de Spectre avec un surcoût de performance nul pour le code non protégé et allant de 0 % à 338 % pour les applications critiques.

[Lire la publication](https://doi.org/10.14722/ndss.2020.24271)

## Meet the Sherlock Holmes’ of Side Channel Leakage: A Survey of Cache SCA Detection Techniques

- **Date de publication :** 2020-01-01
- **Pertinence :** 85/100
- **Conférence / Revue :** IEEE Access *(source : OpenAlex)*

Cet article présente une étude bibliographique détaillée sur les techniques de détection des attaques par canal auxiliaire basées sur le cache (Cache SCA). Les auteurs identifient un ensemble de caractéristiques importantes pour classifier et comparer ces méthodes, soulignent des observations clés et discutent des défis futurs pour la recherche.

[Lire la publication](https://doi.org/10.1109/access.2020.2980522)

## Defending Against Flush+Reload Attack With DRAM Cache by Bypassing Shared SRAM Cache

- **Date de publication :** 2020-01-01
- **Pertinence :** 75/100
- **Conférence / Revue :** IEEE Access *(source : OpenAlex)*

Cet article présente ByCA, une approche de sécurité exploitant le cache DRAM (cache L4) pour contrer les attaques par canal auxiliaire de type Flush+Reload. En contournant le cache SRAM partagé (L3) pour les blocs ciblés et en redéfinissant l'instruction clflush, ByCA élimine les différences de temps d'accès exploitées par l'attaquant, annulant ainsi l'attaque sans dégrader les performances.

[Lire la publication](https://doi.org/10.1109/access.2020.3027946)

## Quick Boot of Trusted Execution Environment With Hardware Accelerators

[Lire la publication](https://doi.org/10.1109/access.2020.2987617)

## SofTEE: Software-Based Trusted Execution Environment for User Applications

- **Date de publication :** 2020-01-01
- **Pertinence :** 75/100
- **Conférence / Revue :** IEEE Access *(source : OpenAlex)*

Cet article présente SofTEE, un environnement d'exécution de confiance (TEE) basé sur le logiciel pour les applications utilisateur, conçu pour pallier les limites des TEE matériels difficilement modifiables. SofTEE assure l'isolement de la mémoire via une rétrogradation du noyau (kernel deprivileging) et un moniteur de sécurité, tout en s'appuyant sur un minimum de fonctionnalités matérielles pour l'attestation, le tout évalué sur une carte Raspberry Pi 3.

[Lire la publication](https://doi.org/10.1109/access.2020.3006703)

## Flush-Detector: More Secure API Resistant to Flush-Based Spectre Attacks on ARM Cortex-A9

- **Date de publication :** 2020-07-01
- **Pertinence :** 85/100
- **Conférence / Revue :** IEEE Symposium on Computers and Communications (ISCC) *(source : OpenAlex)*

Cet article présente Flush-Detector, une API de vidage de cache sécurisée conçue pour atténuer les attaques Spectre basées sur les instructions flush sur les processeurs ARM Cortex-A9 MPCore. L'approche détecte ces attaques en temps réel, réduit le taux de succès des attaques à moins de 1% et présente un surcoût temporel d'environ 17,7% par rapport à l'API de vidage de cache d'origine.

[Lire la publication](https://doi.org/10.1109/iscc50000.2020.9219627)

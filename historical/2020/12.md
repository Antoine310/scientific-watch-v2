## SRACARE: Secure Remote Attestation with Code Authentication and Resilience Engine

- **Date de publication :** 2020-12-10
- **Pertinence :** 90/100
- **Conférence / Revue :** International Conference on Embedded Software and Systems *(source : OpenAlex)*

Cet article présente SRACARE, un cadre de sécurité destiné aux appareils embarqués et IoT, combinant attestation à distance/locale, démarrage sécurisé et mécanisme de récupération intégré. Le prototype est implémenté sur un processeur RISC-V 32 bits basse consommation déployé sur un FPGA Artix 7.

## SeRoT: A Secure Runtime System on Trusted Execution Environments

- **Date de publication :** 2020-12-01
- **Pertinence :** 90/100
- **Conférence / Revue :** IEEE International Conference on Trust, Security and Privacy in Computing and Communications (TrustCom) *(source : OpenAlex)*

Cet article présente SeRoT, un nouveau système d'exécution sécurisé pour les environnements d'exécution de confiance (TEE) sur une plateforme RISC-V. Il vise à protéger l'interface hôte aux niveaux binaire et application pour empêcher l'adversaire d'interagir via des messages malveillants, offrant ainsi une alternative environ 10% plus rapide que Keystone sur deux benchmarks.

[Lire la publication](https://doi.org/10.1109/trustcom50675.2020.00018)

## Library Implementation and Performance Analysis of GlobalPlatform TEE Internal API for Intel SGX and RISC-V Keystone

- **Date de publication :** 2020-12-01
- **Pertinence :** 75/100
- **Conférence / Revue :** IEEE International Conference on Trust, Security and Privacy in Computing and Communications (TrustCom) *(source : OpenAlex)*

Ce travail propose une implémentation sous forme de bibliothèque des API internes TEE de GlobalPlatform (GP) pour assurer la portabilité logicielle entre différents environnements d'exécution de confiance, spécifiquement évaluée et comparée sur Intel SGX et RISC-V Keystone par rapport à OP-TEE sur Arm TrustZone.

[Lire la publication](https://doi.org/10.1109/trustcom50675.2020.00161)

## RISCGuard: RISC-V Static Analysis Framework for Detecting Microarchitectural Vulnerabilities

- **Date de publication :** 2026-10-11
- **Pertinence :** 90/100

Cet article présente RISCGuard, un cadre d'analyse statique pour détecter les vulnérabilités microarchitecturales et les canaux auxiliaires dans le code assembleur RISC-V. Utilisant l'analyse de flux de données et le suivi de taint, l'outil identifie dix classes de vulnérabilités, incluant des variantes de Spectre et des attaques temporelles, avec une précision globale de 99,6 % sur un jeu de données de test étendu.

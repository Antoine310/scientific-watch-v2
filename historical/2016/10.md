## C-FLAT: Control-Flow Attestation for Embedded Systems Software

- **Date de publication :** 2016-10-24
- **Pertinence :** 90/100
- **Conférence / Revue :** ACM SIGSAC Conference on Computer and Communications Security (CCS) *(source : OpenAlex)*
- **Repère de veille :** conférence prioritaire pour la lecture (liste interne, pas un classement ICORE)

C-FLAT est une solution d'attestation à distance du flux de contrôle pour les systèmes embarqués et les objets connectés. Contrairement aux approches statiques, elle permet de vérifier le chemin d'exécution d'une application à l'exécution sans nécessiter le code source. Un prototype complet a été implémenté sur Raspberry Pi en utilisant ARM TrustZone et évalué sur une application cyberphysique réelle.

## Trusted Execution Development: Designing a Secure, High-Performance Remote Attestation Protocol

- **Date de publication :** 2016-10-24
- **Pertinence :** 75/100
- **Conférence / Revue :** Prépublication (conférence non vérifiée) *(source : OpenAlex)*

Cet article propose une méthode pour combiner l'attestation des extensions Intel Software Guard Extensions (SGX) avec le protocole Transport Layer Security (TLS). L'objectif est d'intégrer des garanties concernant le programme, l'environnement d'exécution et l'identité de la machine directement dans une négociation TLS normale. Les auteurs ont implémenté un serveur de base utilisant SGX/TLS et présentent des détails de performance ainsi que des leçons tirées du développement.

[Lire la publication](https://digitalcommons.wpi.edu/cgi/viewcontent.cgi?article=2144&context=mqp-all)

## CATalyst: Defeating last-level cache side channel attacks in cloud computing

- **Date de publication :** 2016-03-01
- **Pertinence :** 75/100
- **Conférence / Revue :** IEEE International Symposium on High-Performance Computer Architecture (HPCA) *(source : OpenAlex)*
- **Repère de veille :** conférence prioritaire pour la lecture (liste interne, pas un classement ICORE)

CATalyst est un mécanisme hybride matériel-logiciel utilisant la technologie CAT (Cache Allocation Technology) d'Intel pour contrer les attaques par canal auxiliaire sur le dernier niveau de cache (LLC) dans le cloud multi-locataire, avec un faible impact sur les performances.

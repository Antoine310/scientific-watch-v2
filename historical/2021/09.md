## Seeds of SEED: A Side-Channel Resilient Cache Skewed by a Linear Function over a Galois Field

- **Date de publication :** 2021-09-01
- **Pertinence :** 90/100
- **Conférence / Revue :** International Symposium on Secure and Private Execution Environment Design (SEED) *(source : OpenAlex)*

Cet article étudie une architecture de cache associatif par ensembles où le biais (skewing) des ensembles de cache est défini par une fonction linéaire sur un corps de Galois. Les auteurs démontrent qu'cette configuration garantit que chaque ensemble de cache d'un domaine de sécurité intersecte exactement une fois chaque ensemble de tout autre domaine, permettant ainsi de perturber les attaques par canal auxiliaire de type Prime+Probe de manière efficace et d'implémenter cette solution matériellement.

[Lire la publication](https://doi.org/10.1109/seed51797.2021.00012)

## Breaking TrustZone memory isolation and secure boot through malicious hardware on a modern FPGA-SoC

## FastSpec: Scalable Generation and Detection of Spectre Gadgets Using Neural Embeddings

- **Date de publication :** 2021-09-01
- **Pertinence :** 75/100
- **Conférence / Revue :** IEEE European Symposium on Security and Privacy *(source : OpenAlex)*

FastSpec est une approche combinant le fuzzing mutationnel et le deep learning pour automatiser la génération et la détection de gadgets Spectre (variante 1). L'article introduit un jeu de données de plus d'un million de gadgets générés par perturbation, un modèle GAN nommé SpectreGAN pour la génération automatique de code assembleur, et un classifieur basé sur des embeddings neuronaux (BERT) pour détecter efficacement ces vulnérabilités dans des logiciels à grande échelle comme OpenSSL.

[Lire la publication](https://doi.org/10.1109/eurosp51992.2021.00047)
